# Евгени Георгиев — персонално портфолио

Българско портфолио за уеб разработка, електронна търговия, Python автоматизации, ERP/API интеграции и дигитално партньорство.

**Работен сайт:** https://websdite.vercel.app (публичната версия се променя едва след одобрение и сливане на branch-а).  
**Основен сайт на Евгени:** https://evgeni-georgiev.com/  
**Контакт:** egeorgiev955@gmail.com

## Архитектура

- `index.html`: един HTML файл със CSS, SVG и JavaScript. Няма build стъпка или npm зависимости.
- `index.gsap.html`: незасегната алтернативна версия на оригиналния шаблон, **не** е персонализирана и не бива да се публикува вместо `index.html`.
- `AGENTS.md`: правила за безопасно редактиране на анимациите.
- `CREDITS.md`, `LICENSE`: авторство и лиценз.

Портфолиото запазва оригиналните CSS scroll-driven анимации, поддръжката на `prefers-reduced-motion` и наследените идентификатори `#opening`, `#depths`, `#day`, `#rooms`, `#rules`, `#members`, `#evenings`, `#made`, `#plans`, `#visit`.

## Контактна форма

Формата **не изпраща съобщение през сървър**. Валидира минимално името и имейла и отваря `mailto:` чернова в имейл приложението на посетителя. Посетителят сам натиска „Изпрати“. Не показвайте потвърждение, че е изпратено съобщение. За надеждно доставяне добавете защитен backend/API с валидация, rate limiting и антиспам преди продукционен старт.

## Редакция и локален преглед

Отворете `index.html` чрез статичен локален сървър, например:

```bash
python -m http.server 8080
```

Проверете на ширини 375 и 1440 px: визуални преливания, навигация, всички CTA, анимации, клавиатурна достъпност, reduced motion, JavaScript console, читаемост на кирилица.

**Не сливайте промени в main без визуална проверка.** Публичната версия е защитена чрез работа в `feat/bg-evgeni-portfolio`.
